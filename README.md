This project displays a menu with several options from which Lightning McQueen can choose from and displays a different message or closes the menu depending on the chosen option.
This project includes several pre-defined functions.
It requires Python 3.14(64-bit).
Challenges encountered: making the user exit the menu after selecting the last option "Quit", solved it by including the quit option in an if statement where I used a break statement to leave the menu when this option is selected, the concept of indentation in python confused me at first and the code was not running, solved it by searching for the correct syntax and adjusting the indentation in code lines.
